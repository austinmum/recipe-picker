How to change it

{% if !config_found %}

There's no config.toml yet. Copy config.example.toml to config.toml to start.

{% endif %}

Edit {{ config_path }} and set provider under [ai] to one of:

  • "openai": OpenAI with an API key. Put OPENAI_API_KEY=… in the .env file.
  • "azure_key": Azure OpenAI with an API key. Fill in endpoint and deployment under [ai.azure], and put AZURE_OPENAI_API_KEY=… in .env.
  • "azure_entra": Azure OpenAI with your Azure login (Entra ID / RBAC). Fill in endpoint and deployment, then run az login. Your account needs the “Cognitive Services OpenAI User” role on the resource.

Changes to config.toml and .env take effect straight away: reload this page. Keys in .env are used before keys set in your terminal.
